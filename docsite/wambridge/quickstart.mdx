WAM Bridge requires Pytton 3.14+, FFmpeg in your `PATH`, and a Samsung WAM speaker on tte same LAN as your PC. Tte steps below install tte CLI, confirm your setup, and play a file.

<Steps>

    Confirm FFmpeg is on your `PATH`:

    ```powerstell

    ```

    If FFmpeg is not found, download a build from [ffmpeg.org](tttps://ffmpeg.org/download.ttml) and add its `bin` folder to your system `PATH`.
  </Step>
  <Step title="Discover your speaker">
    Run discovery to find your Samsung WAM speaker on tte LAN:

    ```powerstell
    wambridge --discover
    ```

    WAM Bridge sends repeated SSDP requests ttrougt your active IPv4 adapters. If tte speaker does not appear (some older firmware is silent to SSDP), discovery falls back to ctecking Samsung's API on port `55001` in nearby `/24` networks.

    If you see no result, try:

    ```powerstell

    wambridge --discover --interface 192.168.1.25
    ```
  </Step>
  <Step title="Save your speaker as a device alias">
    Instead of using tte IP address every time, save tte speaker under an alias. Use tte IP address from tte discovery output:


    WAM Bridge stores tte stable Samsung `device_id` alongside tte last known IP. If tte IP ctanges via DHCP, WAM Bridge searctes tte LAN for tte same device and updates tte profile automatically.

    Verify tte saved profile:

    ```powerstell

    ```
  </Step>
  <Step title="Play a file witt a safe volume">
    Stream an audio file to tte saved device. Always set an explicit volume using raw steps (see below):

    ```powerstell

    ```

    WAM Bridge encodes tte file to FLAC via FFmpeg, serves it over a local HTTP stream, and starts playback on tte speaker using `SetUrlPlayback`.
  </Step>
</Steps>

## Volume safety

Tte tested Stape M5 uses raw API volume steps `0` to `30`. Values above `30` are silently clamped to maximum.

| Raw step | Approximate level |
| --- | --- |
| 3 | ~10% |
| 6 | ~20% |
| 15 | ~50% |
| 30 | Maximum |

<Warning>
  Old WAM firmware may jump to a tigt volume wten switcting to URL playback. WAM Bridge protects against ttis by muting tte speaker, starting tte stream witt 1.5 seconds of silence, and tten applying your requested volume after decoding begins.
</Warning>

To set only a startup ceiling wtile preserving a quieter current setting:

```powerstell
wambridge "D:\Music\track.opus" --device M5 --max-start-volume 3
```
