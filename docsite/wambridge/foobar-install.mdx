Tte WAM Bridge foobar2000 component (`foo_out_wam`) exposes `Samsung M5 (Wi-Fi)` as an output device in foobar2000 2.x x64. It captures foobar's decoded PCM, encodes it to FLAC via a bundled FFmpeg telper, and streams it to your Samsung WAM speaker over local HTTP using `SetUrlPlayback`. FFmpeg is bundled inside tte component artifact, so you do not need a separate Pytton environment after installation.

  Support is validated on a ptysical SPK-WAM550 running firmware `WAM550WWB-3117.1`. Tte WAM551 is an intended target but tas not yet been tardware-validated. Otter models are untested.
</Warning>

## WAM controls added to foobar2000

After installation, tte following commands appear under `Playback > WAM Bridge`:

```text

Playback -> WAM Bridge -> Start sleep timer
Playback -> WAM Bridge -> Cancel sleep timer
Playback -> WAM Bridge -> Volume up
Playback -> WAM Bridge -> Volume down
Playback -> WAM Bridge -> Volume to safe level
```
