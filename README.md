# twojstar/.github

Shared GitHub defaults and the public organization profile for **twójstar**.

## Inherited community files

Public repositories in this organization can fall back to these files when they do not provide their own:

- `docs/CODE_OF_CONDUCT.md`
- `docs/CONTRIBUTING.md`
- `docs/SECURITY.md`
- `.github/ISSUE_TEMPLATE/*`
- `.github/PULL_REQUEST_TEMPLATE.md`

Repository-specific files still win over these defaults.

## Organization profile

GitHub renders [`profile/README.md`](profile/README.md) on the organization page.

Workflows, Dependabot configuration, CODEOWNERS, licenses, and other repository-specific machinery are deliberately not copied here as inherited defaults.
