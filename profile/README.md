A home for open-source projects, tiny utilities, feeds, apps, experiments, and automation that somehow became infrastructure.

Projects are moving here gradually from [`trvny`](https://github.com/trvny). Until a repository is transferred, its existing `trvny/*` home remains canonical.

### Current orbit

- [feedseek](https://github.com/trvny/feedseek) · feeds made where there were none, and better where there already were
- [kanarek](https://github.com/trvny/kanarek) · reader, radio, and assorted useful bird behavior
- [wambridge](https://github.com/trvny/wambridge) · making Samsung WAM speakers cooperate with this century
- [tvpi](https://github.com/trvny/tvpi) · IPTV tooling and web bits
- [trvny](https://github.com/trvny/trvny) · experiments, benches, bots, Workers, and the cupboard where the cables live

<sub>Migration is incremental. No ceremonial forklift required.</sub>
